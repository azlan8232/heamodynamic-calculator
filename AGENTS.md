This repository contains an acute hemodynamic assessment calculator intended for education and reference. Preserve the existing calculation behavior and clinical caution in the README. Validate formula changes and avoid presenting outputs as substitutes for clinical judgment.

## Universal AI handover protocol

When the user says `HANDOVER`, `HANDOVER CODEX`, `LIMIT NEAR`, `EXPORT CONTEXT`, or `CONTINUE ELSEWHERE`, prioritize a portable continuation package. You cannot observe remaining usage quota.

Include verified objective, deliverables, completed/partial/pending tasks, important decisions, repo branch/commit, relevant paths, blockers, actual commands/tests and results, prioritized next actions, acceptance criteria, and a standalone paste-ready continuation prompt. Request a return report listing files changed, validation, blockers and next actions.

Never invent completed work, verified clinical evidence or tests. Never include credentials or patient identifiers. If explicitly asked to save a durable record, review and update `HANDOVER.md`; otherwise return it in chat. Do not automatically merge, deploy or push unrelated changes.
